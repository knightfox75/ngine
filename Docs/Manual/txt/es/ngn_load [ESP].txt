- Método
NGN_TextureData* Texture(const std::string& filepath);

- Descripción
Carga una imagen en formato PNG y la convierte a datos de textura.
El tamaño máximo de imagen soportado es de 8192x8192 píxeles.
Devuelve NULL en caso de error.

- Ejemplo
NGN_TextureData* bg_grid = ngn->load->Texture("data/png/grid.png");

--------------------------------------------------------------------------------

- Método
NGN_TiledBgData* TiledBg(const std::string& filepath);

- Descripción
Carga los datos de un fondo de tiles en formato .tbg (Ver las utilidades adjuntas de la librería).
El tamaño máximo del tileset es de 8192x8192 píxeles.
Devuelve NULL en caso de error.

- Ejemplo
NGN_TiledBgData* tiles_bg_front = ngn->load->TiledBg("data/bg/bg_front.tbg");

--------------------------------------------------------------------------------

- Método
NGN_IndexedTiledBgData* IndexedTiledBg(
    const std::string& bg_file,				// Archivo de tiles + mapa (.itb)
    const std::string& pal_file,			// Archivo de la paleta de colores
    const std::string& cyc_file = ""		// (Opcional) Archivo de ciclos de animación
);

- Descripción
Carga los datos de un fondo de tiles indexado en formato .itb junto con su archivo de paleta de colores (.pal) y opcionalmente, un archivo de ciclos de animación de paleta .cyc (Ver las utilidades adjuntas de la librería). Devuelve NULL en caso de error.

- Ejemplo
NGN_IndexedTiledBgData* idx_bg = ngn->load->IndexedTiledBg("data/bg/stage1.itb", "data/bg/stage1.pal", "data/bg/stage1.cyc");

- Método
NGN_TextFont* TrueTypeFont(

- Método
bool SpriteAsRawVector(
    const std::string& filepath,                // Archivo a cargar

- Método

[Primera sobrecarga]
std::string TextFile(const std::string& filepath);

[Segunda sobrecarga]
bool TextFile(
    const std::string& filepath,            // Ruta del archivo
    std::vector<std::string>& text_lines    // Buffer de destino
);

- Descripción
Lee el archivo de texto de la ruta especificada y lo devuelve como un string (primera sobrecarga) o almacena las líneas de texto del archivo en el vector dado y devuelve true o false según el éxito de la operación (segunda sobrecarga).

- Ejemplo

[Primera sobrecarga]
std::string text = ngn->load->TextFile("data/script.txt");

[Segunda sobrecarga]
std::vector<std::string> buffer;
ngn->load->TextFile("data/script.txt", buffer);

- Método
int32_t LoadFile(
    const std::string& filepath,    // Ruta del archivo
    std::vector<uint8_t>& data      // Vector de datos
);

- Descripción
Lee el archivo de la ruta especificada desde el sistema de archivos del dispositivo o desde un paquete de archivos (ver SetDisk() y SetPackage()) y coloca los datos en el vector dado. Si se lee el archivo desde un paquete y este está encriptado, se desencriptará el contenido automáticamente. El método devuelve el número de bytes leídos o -1 en caso de error.

- Ejemplo
std::vector<uint8_t> buffer;
int32_t file_length = ngn->load->LoadFile("data/stage.bin", buffer);

--------------------------------------------------------------------------------

- Método
int32_t LoadFileChunk(
    const std::string& filepath,    // Ruta del archivo
    std::vector<uint8_t>& data,     // Vector de almacenamiento
    uint32_t offset,                // Byte de inicio de lectura
    uint32_t length                 // Número de bytes a leer
);

- Descripción
Carga un fragmento específico de un archivo desde el origen predeterminado (ya sea desde el sistema de archivos o desde un paquete de datos). Si el archivo se encuentra encriptado, el método lo desencriptará automáticamente durante la carga. Devuelve el número de bytes leídos o -1 en caso de error.

- Ejemplo
std::vector<uint8_t> chunk;
int32_t bytes_read = ngn->load->LoadFileChunk("data/assets.pkg", chunk, 1024, 512);

--------------------------------------------------------------------------------

- Método
void SetDisk();

- Descripción
Establece el sistema de archivos del dispositivo como el origen predeterminado de datos para todos los métodos de carga.

- Ejemplo
ngn->load->SetDisk();

--------------------------------------------------------------------------------

- Método
bool SetPackage(
    const std::string& pkg_file,    // Archivo empaquetado
    std::string key = ""            // Clave de encriptación (opcional)
);

- Descripción
Establece un archivo empaquetado creado con la herramienta NGN_FileSystem como el origen predeterminado de datos para los métodos de carga. Si los archivos del paquete están encriptados, deberá proporcionarse la clave de encriptación en el segundo parámetro. Devuelve true si el paquete se configuró correctamente o false en caso contrario.

- Ejemplo
ngn->load->SetPackage("gamedata.pkg", "myawesomekey");

--------------------------------------------------------------------------------

if (ngn->load->PackageEnabled()) {
    // Origen: paquete de datos
