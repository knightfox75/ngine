- Tipo
NGN_GPIO_MODE

- Descripción
Define el modo de funcionamiento de un puerto GPIO, de forma equivalente al pinMode() de Arduino. Se utiliza como parámetro del método PortMode(). Valores disponibles:
NGN_GPIO_MODE.input — Entrada digital estándar, sin resistencia de pull interna.
NGN_GPIO_MODE.output — Salida digital.
NGN_GPIO_MODE.input_pullup — Entrada digital con resistencia de pull-up interna activada.
NGN_GPIO_MODE.input_pulldown — Entrada digital con resistencia de pull-down interna activada.

- Ejemplo
ngn->gpio->PortMode(17, NGN_GPIO_MODE.output);

	MÉTODOS de la clase

--------------------------------------------------------------------------------

- Método
bool PortMode(uint8_t port_id, uint8_t mode);

- Descripción
Configura el modo de funcionamiento de un puerto GPIO (numeración BCM). Debe llamarse antes de usar DigitalWrite() o DigitalRead() sobre ese puerto. Si el puerto ya tenía un modo asignado previamente, se reconfigura con el nuevo modo. Devuelve TRUE si la operación se ha realizado con éxito, o FALSE si el número de puerto no es válido o se ha producido un error al reservarlo. Fuera de una Raspberry Pi el módulo GPIO no está disponible, por lo que este método no tiene ningún efecto y siempre devuelve FALSE.

- Ejemplo
ngn->gpio->PortMode(17, NGN_GPIO_MODE.output);

--------------------------------------------------------------------------------

- Método
bool DigitalWrite(uint8_t port_id, bool value);

- Descripción
Escribe un valor digital en un puerto previamente configurado como OUTPUT mediante PortMode(). El valor TRUE equivale a nivel alto (HIGH) y FALSE a nivel bajo (LOW). Devuelve FALSE si el puerto no es válido, si no tiene ningún modo asignado, o si su modo actual no es OUTPUT.

- Ejemplo
ngn->gpio->DigitalWrite(17, true);

--------------------------------------------------------------------------------

- Método
bool DigitalRead(uint8_t port_id);

- Descripción
Lee el valor digital de un puerto previamente configurado como INPUT, INPUT_PULLUP o INPUT_PULLDOWN mediante PortMode(). Devuelve TRUE si el puerto está a nivel alto y FALSE si está a nivel bajo, si el puerto no es válido, si no tiene ningún modo asignado, o si su modo actual no es de entrada.

- Ejemplo
bool state = ngn->gpio->DigitalRead(27);

--------------------------------------------------------------------------------

- Método
void ReleasePort(uint8_t port_id);

- Descripción
Libera un puerto previamente reservado mediante PortMode(), dejándolo disponible para ser configurado de nuevo. No tiene ningún efecto si el puerto no es válido o si no tenía ningún modo asignado.

- Ejemplo
ngn->gpio->ReleasePort(17);

--------------------------------------------------------------------------------

- Método
void ReleaseAllPorts();

- Descripción
Libera todos los puertos GPIO reservados hasta el momento mediante PortMode().

- Ejemplo
ngn->gpio->ReleaseAllPorts();

--------------------------------------------------------------------------------

- Método
bool IsAvailable();

- Descripción
Indica si el módulo GPIO se ha inicializado correctamente durante el arranque de la librería y está listo para ser usado. Su valor siempre será FALSE fuera de una Raspberry Pi, o en una Raspberry Pi si no ha sido posible abrir el chip GPIO del sistema.

- Ejemplo
if (ngn->gpio->IsAvailable()) ngn->gpio->PortMode(17, NGN_GPIO_MODE.output);
